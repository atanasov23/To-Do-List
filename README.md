# To-Do-List
A simple To-Do List web application built with Node.js, Express, HTML, CSS, and JavaScript.

# ✅ To-Do List Application

## 📌 Описание на проекта

Това е уеб приложение за управление на задачи (To-Do List), разработено с отделени **frontend** и **backend** части.

Приложението позволява на потребителя да:
- добавя нови задачи;
- редактира съществуващи задачи;
- отбелязва задачите като завършени;
- изтрива задачи;
- получава съобщения при грешно въведени данни.

Frontend частта отговаря за визуалната част и взаимодействието с потребителя, а backend частта обработва заявките и съхранява информацията.

## Как се пуска проектът

1. Отворете терминал в папката `server`.

2. Инсталирайте зависимостите:

npm install

3. Стартирайте сървъра:

node server.js

4. Отворете файла `frontend/index.html` в браузър.

След стартиране frontend частта ще се свърже автоматично с Node.js сървъра на порт 3000.


✅ Основни функционалности
Добавяне на задачи

Потребителят може да създава нови задачи, които се записват в сървъра.

Редактиране

Чрез бутона за редакция задачата може да бъде променена и запазена.

Завършване на задача

Задачите могат да бъдат маркирани като изпълнени.

Изтриване

Ненужните задачи могат да бъдат премахнати.

Валидация

Приложението проверява:

дали има въведен текст;
дали текстът е достатъчно дълъг;
дали съществува избраната задача.
Обработка на грешки

Използва се try...catch за обработване на проблеми при комуникацията между frontend и backend.

Какво може да се добави в бъдеще

Възможни подобрения:

добавяне на база данни (MongoDB/MySQL);
регистрация и вход на потребители;
категории на задачите;
приоритети;
срокове за изпълнение;
търсене и филтриране;
публикуване онлайн.
